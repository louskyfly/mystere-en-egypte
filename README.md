# Mystère en Égypte — jeu interactif

Adaptation de l'enquête de **Julien Ferrand** (2018) pour une classe de 6e.
Jeu HTML5 autonome, jouable sur iPad en paysage.

## Jouer

Ouvrir `index.html` ou la page GitHub Pages du dépôt.

Les élèves font l'enquête **par binôme** : ils entrent leurs deux prénoms et noms au départ, lisent les questions dans le jeu et répondent sur une **copie papier**. Le jeu ne corrige pas les réponses et ne donne aucun indice.

## Version classe

Le suivi en temps réel des binômes et le corrigé nécessitent le serveur local fourni dans le dossier complet (non exécuté par GitHub Pages). Voir `README.md` du dossier de livraison.
